# Källbrinksskolan — Homework & Tests dashboard

Open **`index.html`** in any browser (double-click or drag into Chrome/Safari/Firefox). It works offline via `file://` — data is embedded in the page, so no local server is needed.

`data.json` is the structured source of truth kept in sync for refreshes. **Grok Bot will refresh** this dashboard when school emails/letters bring new homework, tests, or parent actions.
